# 狮猎七式 · Seven Ways a Lion Hunts

用粒子动画演绎狮子的七种典型捕猎方式：潜近、单狮奔袭、驱赶、伏击、扇形散开、包抄合围、突发机会。

- 每一幕的结局按书中该方式的真实成功率抽签
- 侧视小窗同步显示狮子姿态
- 条件实验：昼夜、风向、植被对成功率的影响
- 展陈模式：网址加 `#exhibit` 即全屏循环播放

资料：George B. Schaller, *The Serengeti Lion: A Study of Predator–Prey Relations* (University of Chicago Press, 1972)，第八章，表 54–59。

动画为示意：动物体型约放大两倍，潜近过程做了时间压缩。
